# Global Graduate Scholar – Find Your Ph.D. Destination

Basit, statik bir PhD programı keşif sitesi (HTML + CSS + JS, framework yok).

## Çalıştırma
`index.html` dosyasını tarayıcıda aç. Hepsi bu.

## Yayınlama (GitHub Pages)
Repo → Settings → Pages → Branch: `main` / root → Save.

## Veri
Programlar `data.js` içindeki `PROGRAMS` dizisinde. Yeni üniversite eklemek için bir satır eklemen yeterli.
